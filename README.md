## Repository layout

```
data-analytics-portfolio/
├── case-studies/          one folder per project
│   └── <project-name>/
│       ├── README.md      the case study
│       ├── images/        anonymised screenshots, diagrams
│       ├── code/          sanitised, illustrative code (optional)
│       └── sample-data/   synthetic data only (optional)
├── templates/             case study template + intake notes
├── docs/                  commit, security and workflow guides
└── scripts/               pre-publish confidentiality check
```

Projects with substantial, runnable code built on public or synthetic data live in their own repositories and are linked from this table.

## Confidentiality

All professional work has been anonymised. Company names, systems, internal URLs, employee, customer and policy data, financial figures that could identify the business, and proprietary code are excluded. Screenshots use masked or synthetic data. Code samples are rewritten to illustrate the technique, not copied from employer systems.
